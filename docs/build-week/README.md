# Cumulore Quest Build Week submission pack

This directory contains the temporary OpenAI Build Week materials for Cumulore
Quest. It does not replace the active production Cumulore milestone.

## Deadline and critical path

Submissions close **Tuesday 21 July 2026 at 5:00 pm Pacific Time**, which is
**Wednesday 22 July 2026 at 10:00 am Sydney time**. Aim to be submitted by
**7:00 am Sydney time** so YouTube processing, permissions, or Devpost do not
consume the final buffer.

Use these documents in order:

1. [`SUBMISSION_READINESS.md`](SUBMISSION_READINESS.md) — evidence-backed status
   and the remaining release gates.
2. [`DEVPOST_WORKSHEET.md`](DEVPOST_WORKSHEET.md) — exact field-by-field content
   and personalisation prompts.
3. [`DEMO_VIDEO_SCRIPT.md`](DEMO_VIDEO_SCRIPT.md) — a sub-three-minute recording
   plan and voiceover.
4. [`JUDGE_HANDOFF.md`](JUDGE_HANDOFF.md) — safe test path, verification commands,
   limitations, and judge notes.

The implementation source of truth remains
[`hackathon-plan.md`](hackathon-plan.md). Release evidence remains in
[`release-checklist.md`](release-checklist.md) and
[`evaluation-evidence.md`](evaluation-evidence.md).

## Official requirements used

The pack is based on the OpenAI Build Week Devpost submission requirements,
judging criteria, dates, and organiser announcements retrieved on 21 July 2026.
The canonical event page is [OpenAI Build Week on
Devpost](https://openai.devpost.com/).

The required submission is a working project in one category, a description, a
public or unlisted YouTube demo under three minutes with voiceover covering
Codex and GPT-5.6, a judge-accessible repository with a complete README, and the
primary Codex `/feedback` Session ID. Cumulore Quest belongs in **Education**.

The four judging criteria are Technological Implementation, Design, Potential
Impact, and Quality of the Idea. The pack makes the evidence for each criterion
easy to find without claiming work that has not been verified.
